# Technology icons

The technology SVGs in `public/static/media/skills/` come from [Devicon v2.18.0](https://github.com/devicons/devicon/tree/v2.18.0/icons). Original and plain SVG variants are used locally.

See [the Devicon license](devicon-LICENSE.txt). Product names and logos belong to their respective owners.

Python, Google Cloud, AWS, Figma and Angular use the full-colour original SVG variants from the same pinned release (updated 6 November 2026). Their original colours are displayed in light mode; dark mode applies the existing monochrome presentation. The existing JavaScript plain variant is retained for its transparent letter cutouts in dark mode.
