# Approved project covers

The owner approved these six AI-generated cover compositions on 6 November 2026. They use the portfolio’s existing product screenshots as visual inputs. The studio backgrounds and device staging were generated with the built-in image-generation tool, then exported to WebP at quality 88 for the website. Full-resolution source previews remain in the local cover-review artifact folders.

- [PitStop](../../public/static/media/projectcover/pitstop-cover-landscape-v3.webp)
- [Carbon Footprint](../../public/static/media/projectcover/carbon-footprint-cover-v3.webp)
- [Wyndra](../../public/static/media/projectcover/wyndra-cover-v2.webp)
- [Glassora](../../public/static/media/projectcover/glassora-cover-v2.webp)
- [DineDesk](../../public/static/media/projectcover/dinedesk-cover-v3.webp)
- [Invoice Picker](../../public/static/media/projectcover/invoice-picker-cover-v3.webp)

Carbon Footprint and Invoice Picker contain clearly labelled, illustrative demo data for the cover compositions. Their values do not establish actual emissions, income, expenses, customers or commercial performance. Existing product and case-study facts are unchanged. Existing third-party artwork visible within app screenshots remains part of those screenshots; generated framing does not establish ownership of that artwork. Blog images were not included in this approval.

At the owner’s request, Carbon Footprint, DineDesk and Invoice Picker were revised to use the same rough charcoal stone bases and white-to-grey studio setting as the other covers. Original app colours and labelled demo values are retained in the source art. The current release displays all six project covers in grayscale in both appearances, across the homepage, project collection and related-work cards. Actual case-study screenshots are unaffected.

PitStop now has separate landscape and portrait exports so wide project cards and the tall desktop homepage frame show the full phone. The [portrait cover](../../public/static/media/projectcover/pitstop-cover-portrait-v3.webp) is used from 1024px upward on the homepage; mobile and collection cards use the landscape version. Both were edited with the built-in image-generation tool using the approved cover as reference.
